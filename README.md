## ⚡ 1-Minute Quick Start

### 1. Install & Setup
```bash
# Using Bun (Recommended)
bun install -g github:yoganataa/naru-agents

# Or using NPM
npm install -g github:yoganataa/naru-agents

# Or using Native Single-File Executable (Windows / Linux / macOS)
naru setup --auto
```

### 2. Scaffold a New Project or Initialize Existing Workspace
```bash
# Create a new Greenfield project with interactive questionnaire wizard
naru new

# Or initialize 5-MCP memory in an existing repository
naru init
```

### 3. Verify AI Models & Diagnostics
```bash
# Inspect and configure AI models & reasoning variants
naru models

# Run full system health & 5-MCP diagnostic check
naru doctor
```

## 🧠 Step 0: Smart Intent Classification & Dynamic Routing

Before delegating to subagents, Naru classifies user prompts into **5 Core Intent Taxonomies**:
1. **`GREENFIELD_CREATION`**: New project from scratch ➔ Launches **Interactive Intake Questionnaire Modal** ➔ Generates `project-brief.md` ➔ Full Production Pipeline.
2. **`FEATURE_MODIFICATION`**: Delta change on existing workspace ➔ Ingests repository topology with `lean-ctx` & `serena` ➔ Standard Feature Pipeline.
3. **`INCIDENT_BUGFIX`**: Error or test failure ➔ Runs blast-radius analysis via `codegraph_impact` ➔ Emergency Hotfix Pipeline.
4. **`INFORMATIONAL_QA`**: Technical questions & architecture discussions ➔ Direct Grounding via `context7` & `codebase-memory-mcp` with full citations (Zero subagent pipeline overhead).
5. **`WORKSPACE_DIAGNOSTIC`**: Maintenance & environment check ➔ Runs 5-MCP scanning or `naru doctor`.

## 🛡️ Core-First Milestone Governance & Anti-Scope Creep

To eliminate cascading architectural regressions and goal drift (ACM TOSEM 2025; arXiv:2505.02709):
- **Core MVP Lock**: Milestone 1 (Core Domain) must pass Quality Gate 4 before secondary features or hardening are introduced.
- **Zero Idea Loss (Backlog Staging)**: New feature requests during Milestone 1 are automatically staged into `.opencode/artifacts/backlog.md`.
- **Interactive Scope Governance Modal**: Naru prompts the user via native OpenCode modal:
  `[1] Focus on Core MVP (Recommended)` | `[2] Amend Milestone Baseline` | `[3] Pivot Project Scope`.

## 🛡️ Universal 8-Platform High-Assurance Security Matrix

N.A.R.U. enforces specialized, research-backed security paradigms across all 8 software archetypes:

1. **🌐 Web Applications & SaaS (Next.js / Remix / MUI)**: Zod input validation, parameterized ORM queries (Zero SQLi), anti-IDOR tenant checks, strict CSP, DOMPurify anti-XSS.
2. **📱 Mobile Applications (.NET MAUI / Expo / Flutter / KMP)**: Hardware-backed `SecureStorage` (iOS Keychain, Android Keystore, Windows DPAPI), `usesCleartextTraffic="false"`, TLS 1.3, deep link validation.
3. **🖥️ Desktop Applications (Tauri / Electron / Avalonia UI)**: Electron `contextIsolation: true` & `sandbox: true`, Tauri IPC capability scoping, `ProtectedData` secret vaults.
4. **🎮 Game Development & Virtual Worlds (Roblox Luau / Unity / Godot)**: Server-Authoritative logic ("Never Trust The Client"), runtime RemoteEvent type checking (`t`/`Guard`), ProfileService DataStore session locking (anti-duplication), `TextService` moderation.
5. **🤖 Bots & Conversational Messaging (WhatsApp / Discord / Telegram / Slack)**: WhatsApp Cloud API `X-Hub-Signature-256` HMAC-SHA256 verification using `crypto.timingSafeEqual` on raw body, Baileys encrypted `creds.json` with `chmod 600`, Discord Ed25519 signature checks, Admin JID/Role RBAC.
6. **⌨️ CLI Tools & Developer Utilities (Node / Bun / Rust / Go / Python)**: Anti-Path Traversal (`path.resolve()`), anti-argument injection, safe temp file nonces (`os.tmpdir()`), safe SIGINT cleanup.
7. **🔌 Backend APIs & Microservices (FastAPI / Go Gin / Elysia / Axum / ASP.NET Core)**: Scoped Secret Broker (`src/config/env.ts`), GraphQL query complexity limiting, timing-safe crypto equality, rate limiting per IP/Token.
8. **📦 Open-Source Packages & SDKs (NPM / Crates.io / NuGet / Wally)**: Zero-Trust Dependency Architecture (ZTD), exact version pinning, export encapsulation, SLSA provenance.

## 🔒 Zero-Trust Dependency Defense (ZTD) & Threat Intelligence

To neutralize Tier-0 / Zero-Day supply chain attacks (e.g. XZ Utils, Log4Shell, compromised maintainer accounts):
- **Pre-Adoption Threat Intelligence**: Researcher-Agent and Dependency-Agent query GHSA and NVD for historical incident proof before proposing libraries, recording results in `.opencode/knowledge/dependency-audit-log.md`.
- **Scoped Secret Broker**: `process.env` is encapsulated and isolated (`src/config/env.ts`); third-party packages are prohibited from reading credentials.
- **Egress Network Sandboxing**: Non-network utility libraries are isolated from opening outbound sockets to attacker C2 servers.
- **Hexagonal Port-and-Adapter Isolation**: Third-party packages are wrapped in adapters for 1-minute hot-swapping or severance.
- **Anti-Hollow Test Audit**: Quality Gate 3 rejects tautological assertions, over-mocking, and zero-assertion tests.
- **Pre-Flight Git Working Tree Guard**: Automatically detects uncommitted manual edits and offers auto-stashing.

## 📋 The 6 Interactive Native Question Modal Touchpoints

Naru utilizes OpenCode's native `question` modal form tool across 6 critical SDLC touchpoints:
1. 🏗️ **Greenfield Project Intake (`naru`)**: Form 6 Parameters (Category, Runtime, Database, Auth, Deployment, MVP Stories).
2. ❓ **Requirement Disambiguation (`pm-agent`)**: Resolves commercial vendor and 3rd-party provider choices (e.g. Stripe vs Midtrans vs Xendit).
3. 🏛️ **Architectural Trade-Off Selection (`architect-agent`)**: Confirms API & paradigm choices (e.g. tRPC vs REST OpenAPI vs GraphQL).
4. ⚠️ **Destructive Migration Sign-Off (`developer-agent` & `hotfix-agent`)**: Requests explicit user confirmation before dropping database tables or executing breaking deletions.
5. 🚨 **Quality Gate 3x Fail Escalation (`naru`)**: Intercepts exhausted retry budgets with an interactive modal: `[Reset Budget +8 / Manual Fix / Abort]`.
6. 🚢 **Deployment Environment Selection (`deploy-agent`)**: Confirms target environment: `[Preview/Staging / Production Live / Dry-Run Script]`.
